START LAB 13 ? MONITORING AND END-TO-END RETRAINING

1. Open a PowerShell terminal at the project root.
2. Confirm the Python environment and project dependencies are ready. This
   checkout uses .venv; activate it with:
       .\.venv\Scripts\Activate.ps1
3. Review data/raw/new_churn.csv and the input reports consumed by
   src/mlops_pipeline/12_drift_analysis.py.
4. To start one monitoring cycle manually, run:
       python .\src\mlops_pipeline\12_monitor_trigger.py
5. Inspect:
       outputs\drift\drift_analysis_report.csv
       outputs\monitoring\monitor_trigger_report.json
       logs\churn_prediction_pipeline_run_log.json
       artifacts\data_load_report.json
       reports\evaluation_report.json
       reports\lifecycle_report.json

The trigger can ingest a new batch and start training, registry, lifecycle, and
inference stages. Check the batch and MLflow tracking configuration before
running it. Deployment is promotion-gated; a candidate that is not promoted
will not update production deployment artifacts.

For GitHub Actions, inspect .github/workflows/lab13_monitoring.yml and confirm
the self-hosted runner's project path, virtual environment, Docker, kubectl,
and Kubernetes context before dispatching the workflow.
